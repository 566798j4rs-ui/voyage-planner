# Prototype Voyage Planner — Finalized Data Version

This app is based on the finalized Excel workbook:
Prototype_Voyage_Planner_v2_Final_Extended_Row15.xlsx

## Data included
- Ports: 96
- Valid real port-to-port distance pairs: 1174
- Highsea is not a physical port. Highsea NM = Speed x 24.

## Run
npm install
npm run dev

## Important
Target Arrival is entered at the destination row.
Target Speed appears on the previous real departure row.
